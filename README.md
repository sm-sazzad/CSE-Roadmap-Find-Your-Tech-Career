## 💡 The "Why" Behind CodePath

Every computer science freshman and self-learner eventually hits the same overwhelming wall:

> *"Everyone tells me to learn Web Development, or do Competitive Programming, or jump into AI, or learn DevOps... But where do I actually start? Which free tutorials are worth my time? How do I stop watching videos and build real projects?"*

**CodePath** was built to turn that confusion into clear momentum. Instead of drowning in endless YouTube playlists and conflicting advice, students can explore **24 structured technology sectors**, follow step-by-step milestones, check off completed concepts, and get personalized advice from an integrated AI mentor.

Plus, because language should never be an obstacle to tech literacy, every roadmap is available in **both natural Bangla (বাংলা) and English**.

## ✨ Key Features

### 🗺️ 24 Exhaustive Career Roadmaps
From foundational CS concepts to cutting-edge domains like Robotics, Quantum/AI, and AR/VR. Each sector provides:
- **Prerequisites & Core Competencies** — Know what to learn first without guessing.
- **Ordered Milestones** — 0-based, curated steps covering theory, tools, and best practices.
- **Curated Free Resources** — High-quality documentation, interactive courses, and tutorials verified for accuracy.
- **Hands-On Portfolio Projects** — Concrete build ideas ranging from beginner exercises to full capstone applications.
- **Career Roles & Job Market Insights** — What titles you will qualify for (e.g. Frontend Engineer, SRE, Pentester).

### 🤖 Gemini AI Career Assistant
A floating, intelligent mentor built with the **Vercel AI SDK v7** and **Google Gemini**:
- **Personalized Progress Integration** — Connected to your MongoDB account. Ask *"What should I learn next?"* or *"আমার প্রগ্রেস কতদূর?"*, and the AI checks your actual saved progress and tells you the exact next step.
- **Page-Aware Intelligence** — If you're on `/sector/cyber-security` and ask *"How do I start?"*, the assistant immediately answers tailored to Cyber Security without needing you to restate the sector.
- **Persistent Chat History** — Seamlessly saves your conversation to `localStorage` so refreshing the page doesn't wipe your advice.
- **Native Link Pills** — Assistant responses generate clean, clickable Next.js links (e.g. `[Web Development](/sector/web-development)`) that navigate smoothly without page reloads.

### 🎯 4-Step Interactive Career Matcher Quiz
Don't know which tech track to pick? Click the **"Career Matcher"** button inside the chat panel:
1. Tap through 4 quick interactive questions: Core Interest, Current Coding Level, Career Goal, and Math Affinity.
2. The AI evaluates your profile and outputs **Top 1–3 Matching Sectors with a % Fit Score** (e.g., *95% Web Development, 85% App Development*), explaining why it fits your background and providing direct roadmap links.

### 🎙️ Real-Time Voice Input (Bangla & English)
- Integrated Web Speech API recognition directly in the chat panel.
- Dedicated language switcher pill (`[বাংলা | ENG]`).
- Continuous listening captures full, complex sentences without abruptly cutting off after 1–2 words.
- $0 API cost and instantaneous real-time transcription.

### 📊 Progress Tracking & Checklists
- Mark roadmap steps as complete as you learn.
- Real-time progress bar shows completion percentage per sector.
- Cloud-synced directly to MongoDB via Better Auth so your learning journey stays saved across devices.

### 🌐 Native Bilingual Support (i18n)
- One-click toggle between **English** and **বাংলা (Bengali)**.
- Authentic translations tailored to South Asian CSE curricula and terminology.

### 🎨 Developer-Grade Dark Aesthetic
- Modern dark theme built with Tailwind CSS v4.
- Subtle glassmorphism, glowing accents, clean borders, and accessible typography.
- Fluid micro-animations powered by **Framer Motion**.
- Fully responsive across desktop, tablet, and mobile drawer interfaces.

## 🛠️ Architecture & Tech Stack

```text
┌─────────────────────────────────────────────────────────────┐
│                       Client Layer                          │
│  Next.js 16 (App Router) + React 19 + Tailwind CSS v4       │
│  Framer Motion + Lucide React + Web Speech Recognition      │
└───────────────┬─────────────────────────────┬───────────────┘
                │                             │
                ▼                             ▼
┌──────────────────────────────┐ ┌─────────────────────────────┐
│         Auth & User          │ │      AI Chat & Mentor       │
│  Better Auth (Mongo Adapter) │ │  Vercel AI SDK (ai v7)      │
│  Google & GitHub OAuth       │ │  @ai-sdk/google (Gemini)    │
│  Session Header Middleware   │ │  Tool Calling & Multi-step  │
└───────────────┬──────────────┘ └──────────────┬──────────────┘
                │                             │
                ▼                             ▼
┌─────────────────────────────────────────────────────────────┐
│                      Data & Database                        │
│  MongoDB Atlas (roadmap_progress & user collections)        │
│  Static JSON Knowledge Engine (sector.json & roadmap.json)  │
└─────────────────────────────────────────────────────────────┘
```

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, React Compiler enabled)
- **Library:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with PostCSS
- **AI Engine:** [Vercel AI SDK (`ai` v7)](https://sdk.vercel.ai/) & [@ai-sdk/google](https://www.npmjs.com/package/@ai-sdk/google)
- **Authentication:** [Better Auth](https://better-auth.com/) + `@better-auth/mongo-adapter`
- **Database:** [MongoDB Atlas](https://www.mongodb.com/) via official driver
- **Animations & Icons:** [Framer Motion](https://www.framer.com/motion/) + [Lucide React](https://lucide.dev/)
- **Markdown & Feedback:** `react-markdown` + `sonner`

## ⚙️ Getting Started

Follow these steps to run CodePath locally on your machine.

### 1. Prerequisites
- **Node.js** 18.18.0 or higher
- **npm**, **pnpm**, or **yarn**
- **MongoDB Database** (A free [MongoDB Atlas](https://www.mongodb.com/) cluster works perfectly)
- **Google Gemini API Key** (Obtain for free from [Google AI Studio](https://aistudio.google.com/))

### 2. Clone the Repository
```bash
git clone https://github.com/sm-sazzad/CSE-Roadmap-Find-Your-Tech-Career.git
cd CSE-Roadmap-Find-Your-Tech-Career
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Create a `.env` file in the root directory (or copy `.env.example`):

```bash
cp .env.example .env
```

Populate the following keys in your `.env`:

```env
# Database
MONGODB_URL=mongodb+srv://<username>:<password>@cluster.mongodb.net/Cse_Roadmap?retryWrites=true&w=majority

# Better Auth
BETTER_AUTH_SECRET=your_super_secret_32_character_key_here
BETTER_AUTH_URL=http://localhost:3000

# OAuth Providers (Optional for local dev)
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

# AI Chatbot (Google Gemini)
GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_api_key_from_ai_studio
GEMINI_MODEL=gemini-2.5-flash

# SMTP Email (Optional - for password reset)
EMAIL_SERVER_HOST=smtp.gmail.com
EMAIL_SERVER_PORT=587
EMAIL_SERVER_USER=your_email@gmail.com
EMAIL_SERVER_PASSWORD=your_app_password
EMAIL_FROM=no-reply@cse-roadmap.com
```

### 5. Start the Development Server
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
